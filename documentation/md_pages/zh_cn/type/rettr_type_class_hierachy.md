## 注册类继承

直到C++26的静态反射为止，在当前的 C++ 标准中，我们无法从特定类型自动提取类层次结构。
因此，程序员需要在每个类中插入一个特定的宏来提供此信息。此外，还需要此宏来检索当前实例的最派生类型信息。

> [!IMPORTANT]
> 在后续，ReTTR将评估并提供对类继承的，采用C++26静态反射实现的实验性特性

您需要在类声明中插入的宏名为：`RETTR_ENABLE()`

假设我们有一个名为 Base 的基础结构体：

```c++
struct Base
{
    RETTR_ENABLE()
};
```

将宏 `RETTR_ENABLE()` 放置在类的某处，无论是在公共类、受保护类还是私有类访问器部分，这都无关紧要。

`RETTR_ENABLE()`会自动生成一个`reflect_this()`提供给用户，另外，会生成一些插桩方法以帮助ReTTR的运行。

然后，接下来，在派生类中，放入相同的宏，但这次参数是父类的名称，在本例中为 Base。

```c++
struct Derived : Base
{
    RETTR_ENABLE(Base)
};
```

使用多重继承时，只需用逗号分隔每个类即可。

```c++
struct MultipleDerived : Base, Other
{
    RETTR_ENABLE(Base, Other)
};
```
因此，最佳实践是。ReTTR 支持注册虚拟基类。

> [!TIP]
> 建议让`RETTR_ENABLE()`使用的参数与您的类继承的顺序保持相同的顺序。因为，在此处声明多重继承的顺序会影响后续获取类属性的方式。
> 若你使用RTTR库，此处的最佳迁移指南便是修改你的代码，将RTTR_ENABLE更改为RETTR_ENABLE便能完成对类继承的迁移
> 
> 如果完全不使用类层次结构，则无需使用此宏。
> 另外，此宏还允许使用名为 `rttr_cast` 的自定义类型转换运算符函数。具体实现方式将在下一章中讨论。

> [!CAUTION]
> 不要在同一类层次结构中注册两次相同的类。

## 总结

- 要检索派生类和基类的元信息或使用 rettr_cast，需要在每个类声明中放置宏：RETTR_ENABLE()。
- 对于不会被继承的类（例如 POD 类），则不需要此宏。
